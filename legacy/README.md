# Legacy source snapshots

This directory preserves the small Python entry points from
[`auto-transpose`](https://github.com/jzjzzzzzzz/auto-transpose) and
[`Auto-Music-Transpose`](https://github.com/jzjzzzzzzz/Auto-Music-Transpose)
as migration references. They are not imported by the maintained package.

Use the `music-score` CLI or the modules in `src/music_score_toolkit` for new
work. The archived source repositories remain available with their complete
Git history, sample assets, stars, and issue records.
